# Independent ecosystem-value evidence packets

One JSON packet per treasury action upgrades `ecosystem_value_profiles.csv` from proposal-only
extraction to independently verified evidence. Every non-unknown field must cite a public HTTPS
source and a byte-for-byte pinned snapshot under `data/input/governance/independent_sources/`.

Proposal anchors and generated dossiers are explicitly disallowed as independent evidence. Adoption,
market-cost, and duplication claims require at least two source domains. The verifier must differ from
the dossier-drafting model, and any material discrepancy blocks verification.
