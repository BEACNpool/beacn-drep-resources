## Admission scope

This book is admitted as technical background for evaluating Cardano parameter changes and hard
forks that affect the eUTxO ledger model, Plutus execution, transaction construction, or smart
contract developer experience. It does not establish facts about any particular governance action
and must not be treated as an endorsement or a substitute for current protocol specifications.
