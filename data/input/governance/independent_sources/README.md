# Pinned independent sources

Public primary-source snapshots used to verify ecosystem value, adoption, delivery history, audits,
market-cost comparisons, duplication, and downside claims. Files are immutable evidence inputs and
must be referenced by URL and SHA-256 from a value-evidence packet.

## Technical references

- `eutxo-fundamentals/` pins Raul Rosa's *eUTxO Fundamentals: Building Cardano Smart Contracts*
  as background for assessing parameter-change and hard-fork effects on Cardano's ledger and smart
  contract ecosystem. It is educational context, not evidence for a specific governance-action claim.
